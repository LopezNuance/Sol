| # | Criterion | Evidence | Status |

| 17 | No committed record carries a status value outside the registered vocabularies. | V0-04 (scope clarified by erratum E-002: lifecycle/staleness/verification; `context_status` open pending post-v0.1 #12); record schema enums for staleness/verification; corpus-wide (37/37). | demonstrated |
| 18 | Illegal status transitions are rejected. | V3-02; PATH-004 (stale → current via direct write); PATH-025 (failed verification while target remains verified). | demonstrated |

| 20 | A human-facing render of an artifact containing stale records visibly discloses them. | `demos/render/stale_disclosure.html` (Disclosures block names the stale/needs_reverification claim); V5-02 + PATH-007 (undisclosed stale content is invalid). | demonstrated |
| 21 | The machine summary alone suffices for an evaluator to answer: what was done, what is claimed, what supports it, what is stale, what failed, and what awaits review. | `machine_summary.schema.json` (Q11: `failures`, `diagnostics`, `open_proposals`, `stale`, `renders`); GOLD-01 `renders/machine_summary.json`; V5-03 (summary-artifact divergence invalid) + PATH-019/PATH-030. | demonstrated |
| 22 | A commit applying a proposal cannot be accepted when the constituent operations diverge from the proposal changeset. | V3-05 changeset matching; PATH-022 (divergent constituent ops rejected). | demonstrated |

| 25 | Cell output contracts are distinct from run-level output bindings. | `cell_014.produces` (authored contract, `contract_hash` per section 18) vs `run_008`/`run_012.output_bindings` (concrete bindings); section 18: executors MUST NOT update the authored cell when binding; the reference executor binds at run time without modifying cells. | demonstrated |

## How to reproduce

```bash
cd sol_validator
python -m solval.make_corpus corpus          # rebuild the 37-case corpus
python -m solval.validate_corpus corpus --strict-extra   # 37/37 expected
python -m solval.mvp_demo                    # regenerate demos/ (12/12 checks)
python -m solval.validate corpus/GOLD-01/artifact.sol.d  # "valid"
python -m solval.validate demos/container/gold01.solnb   # "valid" (.solnb directly)
```
